# telegram-userbot

Доступ к **личному Telegram-аккаунту владельца** (Telethon, MTProto) — отдельный аккаунт-человек,
НЕ бот, через которого ты сейчас общаешься. Всё делается ТОБОЙ прямо в этом чате: настройку ты
проводишь через приватное меню бота, а работу — через MCP-тулы
`connection__telegram-userbot__<tool>` (ищи их через `connection_search`).
**Пользователь только пишет в чат — терминал он не трогает.**

## ⚠️ Сначала — предупреди и получи согласие

Автоматизация личного аккаунта нарушает ToS Telegram и может привести к **бану аккаунта**
(особенно отправка). Одной фразой скажи владельцу, что это на его страх и риск и что безопаснее
всего только чтение. Продолжай, только если он согласился.

## Шаг 1. Подключён ли аккаунт?

Вызови `login_status`.

- `connected` → всё готово, переходи к работе (Шаг 4).
- `not_connected` → нужен онбординг (Шаг 3), но сперва проверь, поднят ли прокси (Шаг 2).
- Если сам вызов падает (сервер недоступен) → прокси ещё не установлен, иди в Шаг 2.

## Шаг 2. Включить прокси через приватное меню

В container production не пытайся менять `/app/.env` и не запускай systemd.

1. Открой экран userbot в `/menu`.
2. Нужны `api_id` / `api_hash` с my.telegram.org. Проведи владельца:
   «Открой https://my.telegram.org → **API development tools** → создай приложение (название любое,
   платформа Desktop) → введи **api_id** и **api_hash** только в секретных шагах меню».
3. Прими значения только через секретные шаги меню: сообщение удаляется до обработки,
   затем данные сохраняются в приватный runtime-файл вне `/app/.env`.
4. Нажми «Включить». Меню создаст bearer token и enable marker; sidecar заметит их сам.

## Шаг 3. Приватный вход по телефону

1. Открой `/menu` → экран **Telegram-userbot** → **Войти по номеру**. Не проси телефон,
   код Telegram или пароль 2FA в обычном диалоге и не передавай их MCP-инструментам.
2. Владелец вводит номер в секретном шаге меню. Бот обязан удалить сообщение до обработки;
   если удаление не удалось, вход не продолжается.
3. Код из Telegram владелец набирает только кнопками маскированной клавиатуры. Цифры не
   появляются в сообщениях. При включённой 2FA меню отдельно запросит пароль тем же секретным
   delete-before-processing шагом.
4. После завершения вызови только read-only `login_status`: `connected` означает, что аккаунт
   подключён. Если код истёк или достигнут лимит попыток, начни новый вход через меню.

Сессия хранится на сервере — повторный онбординг после рестарта не нужен.

## Шаг 4. Работа с аккаунтом

Ходовые тулы (полный список — `connection_search`):

- Чтение: `get_chats`, `list_chats`, `get_history`, `list_messages`, `get_messages`.
- Поиск: `search_messages` (внутри чата), `search_global`, `resolve_username`.

Инструменты отправки, редактирования, удаления, вступления, инвайтов и реакций отсутствуют.
Не обещай выполнить такие действия и не пытайся обходить registry через `bash`.
